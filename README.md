Additional file 6: supplementary software
==========================================

Contents: analysis source code for the study's computational pipeline
"Multi-modal feature fusion integrating standardized indocyanine green fluorescence parameters and molecular signatures for predicting anastomotic leakage after colorectal cancer surgery: a bioinformatics-driven virtual cohort study"

Run order (each script reads the outputs of the previous ones):
  01/01b/01c  data download (cBioPortal REST API; rate-limited, ~1 day)
  02, 03      preprocessing, discovery and validation cohorts
  04          WGCNA (pure-Python implementation, sensitivity grid)
  05          pathway enrichment and GSEA
  06          ssGSEA immune infiltration
  07          virtual ICG cohort generation (fixed seed 20260828)
  08, 09      model training, fusion, ablation, SHAP
  10          external validation, DCA, calibration, survival
  11          all figures (tif + svg, 300 DPI)
  13          per-module GO/KEGG/Reactome enrichment (Tables S2-S4)

gradio_app.py runs the web calculator described in the manuscript.
Random seed fixed at 20260828 for full reproducibility.
Tables S5-S7 are regenerated by scripts 06, 08/09 and 10 respectively.

Environment
-----------
Python 3.13 (tested on 3.13.12, Windows and Linux).
Install with:   pip install -r requirements.txt
or with conda:  conda env create -f environment.yml
Exact versions used for every result in the paper:

Reproducibility
---------------
Every stochastic step is seeded with 20260828 (see cfg.py). Re-running the
pipeline in this order reproduces all tables and figures in the manuscript.
